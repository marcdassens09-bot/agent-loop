🚀 Déploiement Render

Déploie MP Solutions IA en 5 minutes!

1

Aller sur Render

Ouvre https://dashboard.render.com dans ton navigateur.

Login avec ton compte Render (ou crée-en un avec GitHub).

2

Créer un Web Service

Clique "New +" en haut à droite.

Sélectionne "Web Service".

3

Connecter GitHub

Dans "Source", clique "GitHub".

Autorise l'accès si c'est ta première fois.

Sélectionne le repo "agent-loop".

Clique "Connect".

4

Configurer le Service

Remplis les champs exactement comme ci-dessous:

Name: mpsolutionsia Environment: Python 3 Build Command: pip install -r requirements.txt Start Command: gunicorn mpsolutionsia_app:app Instance Type: Free
5

Ajouter la Clé API (IMPORTANT!)

Scroll jusqu'à "Environment".

Clique "Add Environment Variable".

Name: ANTHROPIC_API_KEY Value: sk-ant-api03-xxxxx
⚠️ IMPORTANT: Remplace sk-ant-api03-xxxxx par ta vraie clé API Anthropic!

Clique "Save Variable".

6

DEPLOY!

Scroll jusqu'en bas.

Clique le gros bouton bleu: "Create Web Service".

Attends 2-3 minutes que Render installe et lance ton app.

7

Vérifier que ça marche

Quand c'est terminé, tu recevras une URL comme:

https://mpsolutionsia.onrender.com

Teste dans ton navigateur:

https://mpsolutionsia.onrender.com/health

Tu dois voir: {"status": "alive"}

Si c'est bon, 🎉 c'est LIVE!
